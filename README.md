# ひらり

縦にスワイプしてイラストを次々見られて、写真を1枚選ぶだけで投稿できるサイトです。
Node.js（Express）とPostgreSQLで動き、Renderにそのままデプロイできます。

## Renderに公開する手順

1. このフォルダの中身をGitHubのリポジトリに push する。
2. Renderのダッシュボードで **New > Blueprint** を選び、そのリポジトリを指定する。
3. `render.yaml` の内容（Webサービス1つ＋Postgres1つ）が表示されるので、そのまま Apply する。
4. ビルドが終わると `https://hirari-xxxx.onrender.com` のようなURLで公開される。

`render.yaml` が `DATABASE_URL`（DBとの接続）と `ADMIN_TOKEN`（管理用の合言葉）を自動で設定します。
手作業での環境変数の設定は要りません。

## 仕組み

- 投稿された写真は、サーバー側で向きを直し、長辺1600pxのJPEGに作り直してPostgreSQLに保存します。
  作り直す過程で、位置情報などのメタデータは消えます。
- 投稿したブラウザには「削除キー」が保存され、そのブラウザからだけ自分の投稿を削除できます。
  ブラウザのデータを消すと、自分の投稿を削除できなくなります。
- 他の人の投稿は「通報」できます。同じ人（ブラウザ）が1つの投稿を通報できるのは1回までです。24時間以内に3人から通報されると自動で非表示になり、通報から24時間たつと件数は数えなおされ（非表示も解除され）ます。
- 投稿にはいいねとコメント（200文字まで）を付けられます。ログインは不要で、ブラウザごとの匿名IDで1人1回のいいねと、自分のコメントの削除を判定しています。ブラウザのデータを消すと別人として扱われます。
- コメントも同じ決まりで通報できます。
- 画像をタップすると拡大表示になります。2本指で拡大と回転、ダブルタップで拡大、下のボタンで90度ずつ回転できます。
- 荒らし対策として、同じIPからの投稿は1時間に12回まで、通報は1時間に30回までです。

## タグ・自分の投稿・おすすめ

- 投稿のときに `#猫 #水彩` のようにタグを5個まで付けられます。人気のタグは候補に出ます。カードのタグを押すと、そのタグの絵だけを新しい順に見られます。
- 右上の四角いボタンで「自分の投稿」の一覧を開けます。このブラウザに保存された削除キーで探すので、別の端末やブラウザのデータを消した後は表示されません。一覧から削除もできます。
- 「おすすめ」では、見ていた時間・いいね・コメント・拡大した絵から好みを推測して、次々に表示します（上にスワイプし続けられます）。「新着」で新しい順に切り替えられます。
- 好みの記録（プロファイル）は、このブラウザの中だけに保存されます。サーバーには保存せず、おすすめを頼むたびに送るだけです。自分の絵は好みに数えません。
- 並べ方は、タグの一致、絵の見た目の近さ（CLIPが有効なとき）、新しさ、人気、少しの偶然、の組み合わせです。2割ほどは好みから外れた絵も混ぜます。見たことのある絵は後ろに回ります。
- タグも特徴の計算も付いていない間は、新しさと人気が中心になるので、おすすめの精度は低めです。

## 規約・共有リンク

- `/terms.html` に利用規約があります。投稿するときは、規約に同意するチェックが必要です（サーバーでも確認します）。
- 規約ページの連絡先は、Renderの Environment に `CONTACT` という名前で追加すると表示されます（メールアドレスやSNSのURLなど）。
- 各カードのシェアボタンで、その絵のリンク（`/p/<ID>`）を共有できます。SNSに貼ると、絵のプレビューが出ます。

## 管理画面とバックアップ

`https://あなたのURL/admin.html` を開き、Renderの `ADMIN_TOKEN` を入れてログインします。

- 投稿数やデータ量などの状況、通報された投稿・コメントの一覧、削除、通報の取り消し（非表示の解除）ができます。
- **バックアップ**: 絵・コメント・いいねを1つのファイル（`.ndjson`）に保存できます。無料のデータベースは約30日で使えなくなるので、期限の前に保存してください。
- **復元**: そのファイルを選ぶと、足りない投稿だけが戻ります。ファイルの最後が欠けているときは、何も変えずに失敗します。
- 合言葉をまちがえ続けると、そのIPは1時間ほど止まります。

## 似ている絵の検出

新しい絵が投稿されると、サーバーがAI（CLIP）で絵の特徴を数字にし、過去の絵と比べます。
似ている度が基準（初期値は85%）以上なら、先に投稿した人の「似ている絵」ボタンに表示されます。

- 先に投稿した人は、2枚を見比べて「盗作だと思う」「セーフ（似ているだけ）」「無関係」を選べます。
- 選んだ結果は、選んだ本人にしか表示されません。後から投稿した人の絵が消えたり、印が付いたりすることはありません。
- 先に投稿した人かどうかは、投稿したブラウザに保存された削除キーで判断します。別の端末や、ブラウザのデータを消した後は確認できません。
- AIが見ているのは絵全体の雰囲気で、盗作かどうかの判定ではありません。似ていても別の絵は多く、逆に描き直された絵は見逃すことがあります。
- 計算は、使うときだけ起動する別のプロセスで行い、2分使われなければ終了します。無料プランのメモリ（512MB）でサイト本体が落ちにくくするためです。
- AIモデルはビルド時に先にダウンロードします（`npm run prefetch-model`）。

設定は `render.yaml` の環境変数で変えます。

| 名前 | 意味 |
| --- | --- |
| `ENABLE_SIMILARITY` | `1` で有効、`0` で無効。サイトが重い・落ちるときは `0` にする |
| `SIMILARITY_THRESHOLD` | 原作者に見せる類似度（0.5〜0.99）。初期値は 0.85 |

### たまった判定を見る

管理者は、判定済みのペアの「類似度」と「選ばれた判定」を一覧できます。しきい値を決める材料になります。

```
curl https://あなたのURL/api/admin/verdicts \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
```

## 管理者として投稿を消す

Renderのダッシュボードで `ADMIN_TOKEN` の値を確認し、投稿のIDを指定して実行します。
投稿のIDは、画像のURL（`/img/<ID>`）に含まれています。コメントを消す場合は `/api/admin/comments/<コメントID>` を使います。

```
curl -X DELETE https://あなたのURL/api/admin/posts/<ID> \
  -H "Authorization: Bearer <ADMIN_TOKEN>"
```

## Renderの無料プランの制限（2026年10月時点）

- Webサービスは、15分アクセスがないとスリープし、再開に約1分かかります。
- 無料のPostgresは容量1GBで、**作成から30日で使えなくなります**。その後14日以内に有料プランへ上げないと、データごと削除されます。バックアップもありません。
- 続けて運用するなら、Postgresを有料プランに変えてください。`render.yaml` の `databases` の `plan: free` を `plan: basic-256mb` などに書き換えるか、ダッシュボードから変更できます。
- 1枚あたり約200〜400KBなので、1GBでおよそ3000〜5000枚です。

## 手元で動かす

```
npm install
DATABASE_URL=postgres://ユーザー:パスワード@localhost:5432/hirari npm start
```

`http://localhost:3000` を開きます。ローカルのPostgres 13以降が必要です。

## ファイル構成

- `server.js` : APIと画像の配信
- `ranking.js` : タグの整形と、おすすめの順位づけ
- `admin-routes.js` : 管理用API（統計・通報・バックアップ・復元）
- `similarity.js` / `embed-worker.js` : 似ている絵の検出（特徴の計算と比較）
- `public/` : 画面（`index.html` / `style.css` / `app.js`）、規約（`terms.html` / `terms.js`）、管理画面（`admin.html` / `admin.js`）、`page.css`
- `render.yaml` : Renderの構成
